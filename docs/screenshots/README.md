# Screenshots

These show the setup on a 1920x1080 laptop screen at 150% scaling.

- The wallpaper is a plain Tokyo Night gradient made with `ffmpeg`. No
  wallpaper images are included in this repository, so set your own with
  `set-wallpaper`.
- The login screen was captured in SDDM's test mode, which hides the power
  buttons. The user name was replaced with "user".
- The boot menu (GRUB) can't be captured from inside Linux, so there is no
  screenshot of it.
